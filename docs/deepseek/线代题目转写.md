# 交接任务：把 355 道线代题的题干和答案转成 Markdown + LaTeX

本文档是交给 opencode 里的 DeepSeek（或其他能看图的模型）的完整任务说明。照本文做完、校验通过后交回，由 Claude 审核后写入题库，接到网站上。

## 1. 背景

这是一个考研数学二刷题站。高数题库已经上线，现在要加《线代臻选题》：355 道题，书上的题号是 **#001–#355**，下文都用这个题号。六章：

| 章 | 名称 | 题号 |
|---|---|---|
| L1 | 行列式 | 1–40 |
| L2 | 矩阵 | 41–115 |
| L3 | 向量 | 116–146 |
| L4 | 方程组 | 147–220 |
| L5 | 特征值与特征向量 | 221–284 |
| L6 | 二次型 | 285–355 |

**任务**：逐题看图，把题干（含选择题选项）和答案转写成 Markdown + LaTeX。网站会用 KaTeX 渲染这些公式。解析不用转，继续用图片。

和高数那次有两点不同，请特别注意：

1. **题目本有印错的地方。** 题目本是别人重新排版的，个别题丢了负号、下标印错。答案本里每题开头的截图是**原书题面**，是对的。所以每道题都要拿题目本的题图和原书题面逐字对照（见第 6 节规则 1）。
2. **没有答案速查。** 答案要从解析图里找（见第 7 节）。

  - 首选 opencode 里的 `deepseek-v4-flash-vision-exp`。普通的 `deepseek-v4-flash` / `deepseek-v4-pro` 不接收图片。
  - 也可以用 opencode 里其他能看图的模型，实际以 opencode 的模型列表为准。
- **只能新建或修改** `content/xiandai/transcribe/out/` 下的文件。

- **必须逐张看图转写。** `pdf_text` 和 `solution_text` 只能用来核对汉字和数字，不能拿它们代替看图。可以写小脚本辅助读写文件。

## 5. 输出格式

按批写文件：每批 20–30 题，同一批只含一章的题，文件名写成 `out/<章>-<起>-<止>.json`，例如 `out/L1-001-030.json`、`out/L1-031-040.json`、`out/L2-041-070.json`。
校验会读取 `out/` 下所有 `.json`（`probe` 开头的除外），**不需要合并**。顶层格式是 `{"questions": [ ... ]}`，每题一个对象：

| 字段 | 内容 |
|---|---|
| `num` | 书上题号（整数，1–355）。 |
| `type` | `choice`（选择题）、`fill`（填空题）或 `solve`（解答、计算、证明题）。 |
| `stem` | 题干，Markdown + LaTeX。选择题不含选项。 |
| `options` | 选择题写 `{"A": "…", "B": "…", "C": "…", "D": "…"}`。其他题型写 `null`。选项本身是图形、没法转写时写 `null`，同时 `figure` 设为 `true`。 |
| `figure` | 题目里有图形时写 `true`，否则写 `false`（线代题很少有图）。 |
| `answer` | 答案，Markdown + LaTeX，规则见第 7 节。选择题只写字母，例如 `"B"`。 |
| `answer_basis` | `label`：解析里明确标了「答案」二字（印刷的【答案】、文字的「答案（D）」、「应填 …」都算）；`derived`：没有标，是从解析过程或结论里得出的。 |
| `mismatch` | **可选。** 题目本和原书题面在数字、符号、字母上不一致时才写：说清题目本印的是什么，例如 `"题目本把第 2 行的 $x_2$ 印成了 $x_3$"`。一致就不要写这个字段。 |
| `confidence` | `high` 或 `low`。 |
| `note` | 30 字以内。`confidence` 为 `low` 时**必填**：写清哪里看不清、哪里拿不准。改正过排版错误时也写在这里。 |

**每做完一批就保存**，中断后可以接着做，已经写好的题不要重做。

## 6. 转写规则

**照抄，不解题。** 不简化、不改写，不补书上没有的步骤。

1. **以原书为准**：
   - 底稿是题目本的题图（`qNNN.png`），标点、断句照题目本；
   - 逐字对照原书题面（`sNNN-1.png` 开头的截图）。**数字、符号、字母、下标**两边不一致时，按原书写，并在 `mismatch` 里写明题目本印的是什么；
   - 只是字体、粗细、排版不同（例如原书矩阵是粗体，题目本是斜体），不算不一致，不用写 `mismatch`；
   - 原书题面截图缺失或看不清时，按题目本写，`note` 里说明。
2. **记号**：
   - 行内公式写 `$…$`；原图里单独成行的公式写 `$$…$$`。
   - 矩阵写 `\begin{pmatrix}…\end{pmatrix}`，行列式写 `\begin{vmatrix}…\end{vmatrix}`，方程组写 `\begin{cases}…\end{cases}`。
   - 增广矩阵、分块矩阵中间有竖线的，写 `\left(\begin{array}{ccc|c}…\end{array}\right)`。
   - 转置一律写 `^{\mathrm{T}}`，例如 `A^{\mathrm{T}}`、`\alpha^{\mathrm{T}}`；伴随写 `A^*`；逆写 `A^{-1}`；秩写 `r(A)`；行列式写 `|A|`。
   - 字母**一律不加粗**：原书的粗体 $\mathbf{A}$、$\boldsymbol{\alpha}$ 也写成普通的 `A`、`\alpha`，全库统一。
   - 省略号：横排 `\cdots`，竖排 `\vdots`，斜排 `\ddots`。
   - 不等号照原图：书上多用斜的 `\leqslant`、`\geqslant`。
   - 函数名用命令：`\sin`、`\ln`、`\max` 等；`\operatorname{tr}` 可以写成 `\mathrm{tr}`。
3. **大小**：行内公式里有分式时用 `\dfrac`，或在开头加 `\displaystyle`，让大小接近原图。
4. **选择题括号**写全角 `（　　）`（两个全角空格），书上的 `[ ]`、`( )` 都换成它。**填空题的空位**写 `$\underline{\qquad\qquad}$`，有几个空就写几个。
5. **去掉书上原来的题号、出处和分值**，比如开头的 `(22)`、`【例 1.3】`、`(2014, 数一、二、三)`、`(本题满分 12 分)`。这些网站自己会显示。
6. **分问** `(I)`、`(II)` 或 `(1)`、`(2)` 各占一段，段与段之间空一行（JSON 里写 `\n\n`），分问的标号保留。
7. **标点照原图**：书上中文句子里常用半角逗号、句号，不要统一改成全角。**公式里一律用半角标点。**
8. **只用 KaTeX 支持的命令。** 可用的环境：`cases`、`aligned`、`array`、`matrix`、`pmatrix`、`bmatrix`、`vmatrix`。不要自定义宏，不要用 `\newcommand`。表格用 Markdown 表格。
9. **书上的错**：明显的排版错误按数学含义改正，并在 `note` 里写明原样；内容上的疑问，例如数字可疑，**不要改**，照原书写，在 `note` 里说明。
10. **拿不准时**：写下你最确定的版本，`confidence` 设为 `low`，在 `note` 里写清是哪一处。

## 7. 答案规则

答案在 `sNNN-k.png` 里。先找「答案」二字：

- **有标注**（`answer_basis: "label"`）：印刷的【答案】块、文字的「答案（D）」、「应填 …」。照抄标注的内容，选择题只写字母。`solution_text` 里出现「答案（X）」时，以它为准。
- **没标注**（`answer_basis: "derived"`）：取解析最后的结论，例如「故 …」「所以 …」「… 为所求」、手写推导的最后一行。只抄书上的结论，不要自己算。

写法：

- 选择题只写字母，例如 `"D"`。
- 填空题写值，例如 `"$2^{n+1}-2$"`，不要带「应填」两个字。
- 解答题每个小问一段（`\n\n` 分隔），按原图标号写成 `①`、`②`……，例如 `"① $a=-1,\\ b=1,\\ c=\\sqrt{2}$;\n\n② $P=…$"`。
- 证明题，或某个小问是证明：写 `证明见解析`；同一题还有求值的小问，照常写结果。
- 一题有好几种解法：写最终结论，不写过程。
- 标注的答案和解析结论对不上：照标注写，在 `note` 里说明。

## 8. 校验

随时可以运行：

```bash
.venv/bin/python -m pipeline.transcribe_xiandai check
```

它会检查：

- **错误**：
  - 355 题齐全，不重复，字段都有；`answer_basis` 只能是 `label` 或 `derived`；写了 `mismatch` 就不能为空；
  - 题型、选项、空位格式正确；`$` 成对；
  - **每一段公式都能被网站用的 KaTeX 渲染**，渲染不了的会列出来并附原因；公式里有全角标点也算错误。
- **警告**：
  - **可能漏字**：把题目本文字里的数字、字母和你的转写比对，找回不到 80% 的题会列出来，请回到原图逐字核对；
  - 开头疑似残留书上的题号、出处，或残留「本题满分」。
- **说明**：低把握题号、答案从解析推出的题号、题目本与原书不同的题号、各题型数量、固定抽查的 40 题。

想自己对照着看，可以运行 `.venv/bin/python -m pipeline.transcribe_xiandai review`，它会生成
`content/xiandai/transcribe/review.html`：左边题图和解析图，右边渲染后的转写。只看某几题：`review --nums 1,44,354`。

## 9. 完成标准与交回

**完成标准**：

- 错误为 0；
- 每条警告都逐一核对过，要么改正，要么确认无误并在 `note` 里写明；
- 低把握题不超过 40 道。

**完成后回复**：

1. `check` 的完整输出。
2. 低把握题号，以及原因分类，例如图片模糊、符号认不出、答案找不到。
3. 题目本与原书不同的题目清单（题号 + 不同之处），也就是所有写了 `mismatch` 的题。
4. 你改正过的排版错误清单（题号 + 原样 + 改成什么）。
5. 你发现的、书上内容本身可疑的地方，包括答案和解析对不上的题。

{"num": 44, "type": "solve", "stem": "已知对于 $n$ 阶方阵 $A$，存在自然数 $k$，使得 $A^k=0$，试证明矩阵 $E-A$ 可逆，并写出其逆矩阵的表达式 ($E$ 为 $n$ 阶单位阵).", "options": null, "figure": false, "answer": "$E-A$ 可逆（证明见解析）；$(E-A)^{-1}=E+A+\\cdots+A^{k-1}$", "answer_basis": "derived", "confidence": "high", "note": ""}

## 11. 中途接手（换模型或换工具继续）

3. 一个批次文件只能由一个执行者写；继续遵守第 2 节的「一次只跑一批」和「禁止批量替换」。
