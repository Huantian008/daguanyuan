## 1. 背景

这是一个考研数学二刷题站。题库有 613 道题（`#001`–`#613`），分六章：

| 章 | 名称 | 题号 | 对应的知识点章节 |

| D | 多元微分 | 399–464 | 07 |

知识点资料在 `knowledge-md/01_…md` 到 `09_…md`，按带编号的小节组织，例如 `### 7.3 泰勒公式`。每个小节有一个固定的 key，例如 `01/7.3`。

**任务**：给每道题标出解题时真正用到的 1–3 个知识点小节。网站会在题目旁边显示这些小节，点开就能看到对应的知识点原文。

| 文件 | 内容 |
|---|---|
| `catalog.md` | **小节目录**：全部 202 个 key、标题和约 120 字的正文摘录。h2 小节会列出它下设的 h3。**只能用这里出现的 key。** |

关于题干文字：`text` 是从 PDF 直接抽的，**公式经常错乱**，例如分式拆成两段、上下标丢失、根号和绝对值消失。

- 结合 `path`、`kp` 和常识还原题意。
- 如果你能看图片，题干还原不出来时打开 `images.question`。需要确认解法时看 `images.answer` 和 `images.solution`。

需要细看某个小节的完整内容时，可以读对应的 `knowledge-md/0X_*.md`，但不要修改。

## 4. 工作方式：两个阶段

### 第一阶段：考点默认值 → `content/linking/kp_defaults.json`

给 178 个考点组各定 1–3 个默认小节，作为同组题目的起点。看组内 2–3 道题再定。格式：

```json
{
  "G001": ["01/1.1"],
  "G004": ["01/7.1", "01/7.2", "01/7.3"]
}
```

做完先运行一次校验（见第 6 节）。第一阶段的错误清零后，再进入第二阶段。

### 第二阶段：逐题标注 → `content/linking/out/<章>.json`

按章分文件：`out/A.json` … `out/F.json`。从考点组默认值出发，读每道题，按实际解法增删。格式：

```json
{
  "questions": [
    {"num": 7, "sections": ["01/7.3", "01/7.2"], "confidence": "high", "note": "分子泰勒展开，分母等价无穷小"},
    {"num": 8, "sections": ["01/6.1"], "confidence": "low", "note": "题干公式残缺，按考点默认"}
  ]
}
```

- `sections`：1–3 个 key，**最重要的放第一个**。
- `confidence`：`high` 或 `low`。
- `note`：30 字以内，写为什么这样标。下列情况**必填**：`confidence` 为 `low`；主小节不在本章对应的知识点章节里（见第 1 节的表）。其他情况可选。
- **每做 10–20 题就保存一次**，中断后可以接着做。已经写好的题不要重做。

## 5. 标注规则

1. **只用 `catalog.md` 里的 key**，不要自造。
2. **按解法标，不按题面标。** 标的是“做这道题要用到的方法或结论”。
   - 例如：二重积分题的被积函数是 $e^{-y^2}$，必须先对 $x$ 积分，要标 `08/3.2`（y 型区域），而不只是“二重积分”。
3. **宁少勿滥。** 每题 1–3 个，通常 1–2 个就够。只是沾边、不影响解题的不标。
4. **主次有序。** 第一个是解题的核心步骤，后面是辅助步骤。
5. **优先选 h3**（例如 `01/7.3`），它比 h2（例如 `01/7`）具体。只有某个 h2 下面没有合适的 h3，或者整个 h2 都用得上时才选 h2。
6. **可以跨章。**
   - 例如：极限题用到积分中值定理，标 `01/7.5`；定积分题用到 Wallis 公式，标 `03/5.3`。
   - 主小节通常在本章对应的知识点章节内；如果不在，`note` 写明原因。
7. **`09` 常用图形与曲线**只在解题必须知道曲线形状时才标。例如求心形线围成的面积，要知道心形线长什么样。
8. **拿不准时**：用该题考点组的默认值，`confidence` 填 `low`，`note` 写清哪里拿不准，比如题干残缺、看不出用哪种方法。
9. 同一考点组的题不必和默认值一致，但如果和默认值**完全不同**，要确认确实是解法不同。校验时会列出这类题。

## 6. 校验

随时可以运行：

```bash
.venv/bin/python -m pipeline.link_questions check
```

它会检查以下内容：

- **错误**：两个阶段的文件格式；每题 1–3 个不重复且存在于目录的 key；613 题齐全且没有重复；`confidence` 的取值。
- **警告**：主小节不在本章对应的知识点章节；结果与考点默认值完全不同。
- **说明**：低把握题号；题目最多的小节；没有题目的小节数；固定抽查的 40 题。

**完成标准**：

- 错误为 0。
- 每条警告都逐一核对过：要么改正，要么确认无误并在 `note` 里写了理由。
- 低把握题不超过 60 道。
