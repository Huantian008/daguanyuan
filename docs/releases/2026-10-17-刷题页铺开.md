# 刷题页铺开上线：发布与验收

2026-10-17 22:02（Asia/Shanghai）完成发布，站点：<https://math.leadertestofcn.site>。

## 交付

- **章节页改成刷题页**（仿 cxyonly.fans 学习区的严选题）：
  - `/bank/<章>` 左侧是本章的小节 › 考点树，每个考点显示「做过 / 总数」和进度条，当前考点高亮；
  - 右侧一个考点一页，题目卡片竖着铺开（最多 18 题），用 `?kp=<序号>` 选考点；
  - 不带参数时打开第一个还有没做过的题的考点；
  - 上一节 / 下一节按考点走，到头时变成上一章 / 下一章；
  - 顶部保留「练这个考点」（原来一题一题的练习）和「整个考点不做了」；
  - 窄屏下考点树收进「目录」按钮。
- **题卡**：
  - 题号、出处、考点路径、难度、建议用时；
  - 文字 / 原图切换，沿用练习页的偏好；
  - 「查看答案」：选择题把正确选项标绿，并标出「正确答案」，有勘误的题同时显示勘误和答案原图；
  - 原图模式下选择题的答案改为显示答案那一行；
  - 「查看解析」：展开解析图；
  - 「不熟练 / 不会 / 掌握」当场自评；
  - 标为不做的题只留题头和「恢复，要做」。
- **打分接口**：新增 `POST /q/{num}/grade`，记录的 mode 为 `browse`，会照常进入复习和热身队列。
  - 同一学习日已经评过的题不再落库，所以连点两次「掌握」不会让复习间隔从 7 天跳到 14 天；
  - 卡片上显示「今天已评」，三个按钮禁用。
- **没有改动的部分**：调度、队列和 SRS 都没改，也没有数据库迁移。收藏、笔记、视频讲解这些参考站有、我们没有的功能直接没做。
