`docs/superpowers/plans/2026-10-20-评价不刷新.md`。

## 交付

- **点评价不再刷新页面**：按钮立刻高亮，评价用 `fetch` 在后台存，页面不跳、滚动位置不变；路由对
  `Accept: application/json` 回这张卡的做题记录面板，脚本换进卡片。没有脚本时照旧整页提交。
- **页面上的计数就地更新**：章节页标题下「做过 X / Y 题」、进度条和目录当前考点；热身 / 到期复习页「今天已评 X / N 题」，
  全评完「← 回首页」变主按钮。
- **没存上不丢**：评价先写进 `localStorage`（`dgy-pending-grades`），服务器确认后才删；没存上时卡片上提示
  「还没存上，联网后会自动补交」，当天再打开网页或网络恢复时补交，过了 04:00 的丢掉。同一题一次只发一个请求，
  最后存下的是最后点的。
- **当天第一次的插入改成 `WHERE NOT EXISTS`**：补交和原请求同时到也只记一条。
- **后退回到浏览器从 HTTP 缓存里拿出的题卡页会重新加载**，因为那份是评价之前的页面。
- **没有改动的部分**：表结构不变，没有数据库迁移；调度、SRS、当天改评价的规则不变。

## 浏览器验收

- **本地 Python 版**（临时数据目录）：
  - 章节页点「不熟练」：页面没有重新加载、滚动位置不变，按钮高亮，「做过 0 / 1 → 1 / 1」、两条进度条到 100%，
    做题记录换成「下次复习 10月21日 · 已做 1 次」；再点「掌握」改成完全掌握，和重新打开页面看到的一致；
  - 连点三下（不熟练、不会、掌握）只发了两个请求，库里一条记录、是「掌握」；
  - 让请求失败：卡片显示「还没存上，联网后会自动补交」，评价留在 `localStorage`；触发 `online` 后补交成功、提示消失；
    失败后直接刷新页面，加载时补交成功；
  - 到期复习页评两题：「今天已评 0 / 2 → 1 / 2 → 2 / 2」，「← 回首页」变主按钮，库里两条记录的 `mode` 都是 `due`；
  - 375 宽手机布局：提示单独占一行在按钮上方，没有横向溢出。
- **线上**：用已有的登录状态检查，未点评价按钮。
  - `/bank/C?kp=2` 引用 `app.js?v=1792482440`，6 张题卡、两处 `js-done`、两条 `js-done-bar`，「做过 6 / 6 题」；
  - 在页面里用不合法的评价（`perfect`）调一次 JSON 打分：200、`application/json`，回来的做题记录和页面上的一致，什么都没记。

## 遗留

- 线上没有实际点评价，以免动真实进度；下次做题时点一下就能看到不刷新的效果。
- 「后退时从 HTTP 缓存拿出的页面重新加载」没有在真机上复现过（要浏览器没把页面留在往返缓存里才会走到）。
