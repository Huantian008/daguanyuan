# 方向键翻节：发布记录

2026-11-10 11:05（Asia/Shanghai）发布到 <https://math.leadertestofcn.site>。用户原话：“加一个用方向键来控制下一节、上一节的功能。比如按右边方向键是下一节，按左边方向键是上一节。……你做完了之后自己测试跑通了，就直接部署上线并push。”计划见 `docs/superpowers/plans/2026-11-10-方向键翻节.md`。

## 修改

- 章节页（`/bank/<章>?kp=<序号>`）按 → 到下一节，按 ← 到上一节；章末的 → 是下一章，章首的 ← 是上一章，筛选条件跟着走，和页面底部的按钮一致。
- 这些情况不翻：正在输入框或笔记里打字、带 Ctrl / ⌘ / Alt / Shift、按住不放的连发、输入法组字中、知识点抽屉或解析大图开着。
- 页面底部两个翻节链接多了 `rel="prev"` / `rel="next"`，页面外观不变。服务端接口和数据库不变。
