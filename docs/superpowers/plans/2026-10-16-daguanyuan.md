# 大观园本地刷题站 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 用本地 PDF（大观严选数二）搭一个可靠的本地刷题站，支持刷题、到期复习和首页统计。

**Architecture:** Python 一体化：pipeline/ 用 PyMuPDF 从 PDF 提取题面/答案/解析/知识页到 content/；dgy/ 是 FastAPI + Jinja2 服务端渲染网站，学习数据存 SQLite（data/app.db）。

**Tech Stack:** Python 3.12, FastAPI, Jinja2, SQLite, PyMuPDF, Pillow, markdown-it-py + mdit-py-plugins, KaTeX 0.16.25 (vendored), pytest.

## 知识点 Markdown 核对结论

**核对范围**

- 第 1 章：和原 PDF 第 10–22 页逐页对照。
- 第 2–9 章：全文检查数学正确性，抽查原 PDF 4 页。
- 全目录：扫描 LaTeX 格式问题。

**总体结论**：主干公式基本正确，但这是“压缩改写”，不是忠实转写。原 PDF 里大量蓝字、红字的手写解题技巧被删掉了。所以网站上以“原版页面”为主，Markdown 作为可以搜索的“文字版”。

**需要修的转写错误**

在项目里的副本上修改，原文件不动；修改内容可以用 git diff 查看。

1. `01` §1.1：“f′ 在区间 I 上有界 ⇒ f 有界”，原文是“**有限**区间”。漏掉这两个字后结论是错的。
2. `01` §10.1：D'Alembert–Cauchy 公式缺了中间项，写成了 `= =L`。应为 `\lim\sqrt[n]{x_n}=\lim\frac{x_{n+1}}{x_n}=L`。
3. `01` §10.3：二重积分定义写的条件是 [a,b]×[c,d]，给的却只有 [0,1]² 的公式。补上一般式。
4. `03` §4.1：`dx/√(eˣ−1) = 2d√(eˣ−1)` 是错的。原文是 `d(eˣ−1)/√(eˣ−1) = 2d√(eˣ−1)`。同时补上漏掉的 `d√(x−1)/x = d arctan√(x−1)`。
5. `02` 第 371 行：`\to` 被写成了 Tab 字符，显示会乱。
6. `08` 第 26–43 行：`\,` 变成了逗号，共 7 行。
7. `09` 第 12、18、30、38 行：`\qquad`、`\quad` 丢了反斜杠。
8. `07`：混合偏导记号和同济教材相反。统一为 `f_{xy}=\frac{\partial^2 f}{\partial x\partial y}`。
9. `03` 第 411 行：公式里的全角冒号移到公式外面，否则 KaTeX 报错。

**原 PDF 本身的问题**（只加批注，不改原结论）

- `05` §7 例 2，∫₀^∞ sin(1/x)/x^α dx：原 PDF 的答案是 0<α<1。严格说收敛范围是 0<α<2，0<α<1 只是绝对收敛的范围。
- `06` 的全微分方程、欧拉方程：原 PDF 标为“数学一二”，但数二大纲没有列出这两项。标注为“拓展”。

## 方案：全部用 Python，服务端渲染

用 FastAPI 和 Jinja2 在服务端生成页面，数据存在 SQLite，前端只用少量原生 JS。

**选这个方案的理由**

- 只有一种语言。内容提取也用 Python，需要的 PyMuPDF 已经装好。
- 没有前端构建流程。即使 JS 出错，表单提交仍然可用。
- 进度只在一个 SQLite 文件里，备份和搬到云上都方便。
- 同一套代码在 Windows 和 Linux/Docker 上都能运行。

**目录结构**

```
E:\大观园\daguanyuan\          ← 新建，git 仓库（PDF 原文件都不动）
  pipeline\    questions.py answers.py solutions.py knowledge.py build.py validate.py
  dgy\         main.py config.py db.py srs.py stats.py studyday.py content.py markdown.py
               routes\(dashboard practice bank knowledge history settings auth).py
               templates\  static\(css js vendor\katex)
  knowledge-md\  Markdown 副本（修正后，纳入 git）
  content\     生成产物，不进 git：manifest.json、题面/答案/解析/知识页的 WebP 或 PNG
  data\        学习数据，不进 git：app.db、backups\
  tests\       start.bat  requirements.txt  README.md
```

**内容和进度分开存放**

- `content\` 随时可以从 PDF 重新生成。
- `data\app.db` 只存你的做题记录、复习状态、“不做”标记和设置。

**需要安装的依赖**（从 PyPI、npm 官方源下载）

- Python 包：fastapi、python-multipart、markdown-it-py、mdit-py-plugins、tzdata、pytest、httpx。tzdata 用来在 Windows 上固定 Asia/Shanghai 时区。
- KaTeX 0.16：约 1MB，放进 `static/vendor`，离线可用。
- 已经装好、直接用的：PyMuPDF 1.27、Pillow、uvicorn、Jinja2、itsdangerous。

## 内容提取（`pipeline\`，在本机运行一次）

**题目（questions.py）**

- 只读章节版 PDF。
- 用正则匹配信息条：`^#(\d{3})\n考点\n原稿第N页 · 出处 · 难度 x ★ · 建议 n 分钟`。
- 题面在页面上的位置 = `Rect(xobject_bbox) * page.transformation_matrix`。每个信息条配它下方最近的 `fzFrm*` 矢量块。
- 按 3 倍分辨率渲染，裁掉白边。
- 不读取 35 天分天信息。

**答案（answers.py）**

- 答案速查的行号 `NN-MMM` 对应题号 = 该章的起始偏移 + MMM。
- 每行的答案图按原分辨率提取。

**解析（solutions.py）**

- 用 `get_toc(simple=False)` 读取书签，可以拿到每条书签在页内的 y 坐标。
- 把 A–F 章的叶子书签和做题本按章顺序对齐，对不上的跳过，预期正好跳过 6 条。用出处里的年份做校验。
- 每题的解析区域 = 从本题书签位置到下一条书签位置，最多跨 4 页。
- 区域内的图片按原分辨率提取。其中 374 张带透明蒙版，合成到白底上。
- 同时保存书签路径（例如“积分计算 / 两函数相乘 / 指对有关”），作为“节”这一级分类。分类层级是：章 → 节 → 考点 → 题。

**知识点（knowledge.py）**

- 《高数合集》和线代 PDF 渲染成页面图片。
- 按 `00_总目录.md` 里的页码表，把每个 Markdown 章节和对应的 PDF 页码区间关联起来。

**汇总与校验（build.py、validate.py）**

- build.py 输出 `content\manifest.json`。
- validate.py 检查：题面、答案、解析各 613 份；文件都存在；年份一致。
- 另外列出 7 道出处文字有乱码、只能靠位置对齐的题，供人工抽查：#17、#277、#279、#284、#324、#335、#340。

## 网站功能（第一版）

**首页**

- 日期和考试倒计时。
- **热身：重做前几天的题。**对应你的习惯，默认取最近 3 个学习日做过的题，不含今天，今天已经重做过的不再出现。天数可以在设置里改。
- **到期复习**：按间隔重复规则，到期的题数。
- **继续上次的练习。**
- **进度**：各章完成度，即做过的题数除以该章的题数，“不做”的题不算在内；可以点开看节和考点。
- **掌握分布条**：完全掌握 / 不熟练或错误 / 完全不会 / 未做。
- **优先巩固**：按“节 / 考点”列出最薄弱的 3 项，每项带“去巩固”按钮。
- **学习趋势**：今日题数、今日用时、连续学习天数、近 30 天柱状图。

**刷题**

- 显示题面图，以及考点、出处、难度星级、建议用时，自动计时。
- 点“显示答案”出答案图，点“看解析”出解析图，然后三档自评。
- 显示答案和解析用 `<details>`，自评用表单 POST 后跳到下一题，所以没有 JS 也能用。
- 快捷键：空格显示答案，S 看解析，1/2/3 自评，→ 跳过。
- 题目来源：热身、到期复习、按章/节/考点（跟课程进度时用）、薄弱题、随机。

**题库**

- 按“章 → 节 → 考点 → 题目”浏览，每题带状态标签。
- 可以按题号、出处年份、考点搜索。
- 单题页显示这道题的做题历史。
- 题目和考点都可以标“**不做了**”。标了的题不进入任何练习队列，也不算进进度；随时可以取消。

**其他页面**

- **知识点**：高数 9 章和线代。每章有两个标签：“原版”是页面图片，可放大；“文字版”是 Markdown 加 KaTeX。题目页可以跳到对应章节：A→01，B→02，C→03/04/05，D→07，E→08/09，F→06。
- **学习记录**：按天列出做过的题。
- **设置**：考试日期、热身天数、密码。

**日期**：“今天”按 Asia/Shanghai 时区计算，每天凌晨 4 点切换。晚上学过零点做的题仍算当天，连续天数不会断。

**可选密码**

- 设置了 `APP_PASSWORD` 才需要登录，题目图片也在登录保护范围内。
- 本机默认不需要密码；上云前必须设置。

**自动备份**

- 每天第一次访问时，用 SQLite 的备份接口把 app.db 复制到 `data\backups\`，保留 14 份。

**复习规则**

`srs.py` 是纯函数。复习间隔分 5 级：1、3、7、14、30 天。热身和到期复习中的自评，都会更新这个状态。

| 自评 | 处理 |
|---|---|
| 完全掌握 | 升一级。第一次做就掌握，直接到第 3 级，7 天后复习 |
| 不熟练或错误 | 降一级，最低到第 1 级 |
| 完全不会 | 回到第 1 级，明天复习 |
