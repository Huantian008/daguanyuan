# 隐藏计时显示，并支持暂停

用户已批准本计划并要求实现、验收及发布。

## 目标与约束

- 默认不显示时间，右上角仅显示普通字重、小号灰色的“查看用时 · 暂停”。
- 展开后显示“用时 00:03 · 收起 · 暂停”；暂停后显示“已暂停”，操作变为“继续”，保留时间显隐状态。
- 暂停只停止累计时间，题目、答案、解析、自评和快捷键保持可用；多次暂停以及暂停中提交均准确记录有效用时。
- 新题及刷新从零开始、默认隐藏、正常计时；切换标签页不自动暂停。
- 共用 CSS/JavaScript，同时更新本地 Python 与 Worker 练习页。不新增依赖、接口或数据库字段，沿用 elapsed 秒数字段。
- 无 JavaScript 时隐藏计时操作，保留原有表单刷题流程。

## 实施与验收

1. 为实际 app.js 添加可控时钟行为测试，并为两套练习页检查默认隐藏与非提交按钮。先确认失败，再实现。
2. 用单调时钟累计运行区间，暂停不计时；显示和表单提交使用同一 elapsed 计算，沿用整数秒舍入方式。
3. 检查默认隐藏、显隐、暂停/继续、多次暂停、暂停中自评、新题重置、标签页切换和快捷键。验证运行 10 秒、暂停 20 秒、运行 5 秒最终仅记录 15 秒。
4. 检查桌面及手机排版、按钮焦点和点击范围，使用临时数据验证真实页面。运行 Python、Worker 测试和类型检查。
5. 审查后合并到本地项目，重新导出并发布现有 Cloudflare 站点；线上使用已有练习页检查，避免写入学习记录。

## 审查重点

- CSS 不覆盖 hidden 属性；无 JavaScript 时不出现无效按钮或计时数字。
- 暂停期间不重置累计时间；隐藏与暂停两个状态相互独立。
- 保留亚秒精度，反复暂停不逐段舍入；提交时重新计算准确用时。
- 窄屏及较长时间显示可换行、不溢出；按钮键盘激活不触发答题快捷键。
- 生成资源版本更新，线上不会继续使用旧脚本与样式。
