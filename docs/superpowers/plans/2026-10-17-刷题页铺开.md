# 刷题页仿 cxyonly.fans：考点树 + 一个考点一页、题目铺开

## Context

用户想要参考站 `cxyonly.fans/math`（学习区 → 严选）那种刷题体验：往下滚着一题题做，而不是现在 `/bank/<章>` 只给「考点 + 题号 chip」、点进去一次只看一题。我们只有严选真题，所以只仿严选这一块；**只做刷题页，其他页面不动**。参考站有、我们没有的东西（收藏、笔记、视频讲解、模拟题/真题切换）直接去掉。后端只加一个打分小接口（用户已同意），调度、队列、SRS 都不改。

参考站页面（Chrome 里实际看过）：
- 左栏是章 › 小节 › 考点三级树，每个节点右侧显示「已做 / 总数」，下面一条细进度条；当前考点高亮。
- 顶栏：返回、考点名（点它可以收起左栏）、`0/3`；右边是「上一节」「下一节」（主色），顶栏底边是一条进度线。
- 右侧**一个考点一页**，题目卡片竖着铺开（单个考点最多 18 题，最重的是 A 章「0/0」）。题卡：题号小方框 · 出处 · 面包屑；题干；选项两列方框；一条分隔线；下面一排按钮：查看答案 / 查看解析 / 不熟练 / 不会 / 掌握。
- 点「查看答案」：正确选项变绿底绿框，右侧标「正确答案」，按钮变浅蓝的「隐藏答案」；点「查看解析」：解析在卡片下方展开，标题是蓝色的「解析」。

## 页面设计（我们的版本）

URL 不变：`/bank/<code>`，用 `?kp=<序号>` 选考点（整章内从 1 开始连续编号）。不带参数时打开**这一章第一个还有没做过题的考点**，全做完就打开第一个。

```
[原顶栏：首页 题库 知识点 学习记录 设置]
┌ 考点树（sticky）──────┐ ┌ ← 题库   函数性质·有界 ▾  2/5        [练这个考点] [上一节] [下一节] ┐
│ 函数极限连续   12/117 │ │━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 进度线                         │
│ ▾ 函数性质      3/9   │ ├──────────────────────────────────────────────────────────────┤
│    奇偶         2/3   │ │ [1] 2019 数二 第7题  函数极限连续 / 函数性质 / 有界  ★★ 8分钟  [原图] ⋯ │
│   ▸有界         0/5 ← │ │ 题干（KaTeX，带图题默认原图）                                   │
│ ▸ 极限        5/135   │ │ ┌A. …────────┐ ┌B. …────────┐                                │
└──────────────────────┘ │ └C. …────────┘ └D. …──正确答案┘  ← 查看答案后                      │
                         │ ────────────────────────────────────────                         │
                         │ 查看答案  查看解析   [不熟练] [不会] [掌握]                        │
                         │ 答案 / 解析图（展开后）                                          │
                         └──────────────────────────────────────────────────────────────┘
```

- 按钮文案用我们自己的三档：**掌握 = mastered、不熟练 = shaky、不会 = unknown**（与现有「完全掌握 / 不熟练/错误 / 完全不会」对应，题卡上用短名）。今天已经评过的题，对应按钮呈选中态，三个按钮都禁用，旁边小字「今天已评」。
- 题卡右上角「⋯」换成一个安静的「不做了」按钮（复用 `exclude_toggle(nums=…)`），以及「详情」链接到 `/q/N`（知识点、做题历史都在那）。已标为不做的题：卡片灰显，只留题头和「恢复，要做」。
- 顶栏保留「练这个考点」（走原来一题一题的练习流程），以及「整个考点不做了」放在考点名的下拉里。
- 上一节/下一节在整章内跨小节走；到头时变成「下一章」/「上一章」，跳到相邻章的第一个/最后一个考点。
- 窄屏（≤ 960px）：左栏收起成顶栏下方的「目录」按钮，点开盖在内容上；没有 JS 时目录直接显示在内容上方。
- 不挂 `data-shortcuts`（那套键盘劫持只为练习页的单题设计）。

## 改动

### 1. 打分接口（两边都加，唯一的后端改动）

`POST /q/{num}/grade`，表单 `grade`、`back`：
- 题不存在 → 404；`grade` 不在 `GRADES` → 什么都不做，303 回去。
- **当天（学习日）这题已有任意 review → 不落库**，303 回去。防止连点两次「掌握」把等级 3→4、间隔 7→14 天（`schedule` 每次 mastered 都 +1，见 `dgy/srs.py:25`）。
- 否则 `db.record_review(conn, num, grade, now(request), "browse")`；303 到 `safe_back(back, f"/bank/{q.chapter}#q-{num}")`。
- `mode="browse"` 无需迁移：`reviews.mode` 是无约束 TEXT，Worker 的 `ReviewInput.mode` 是 `string`；它也会正常进热身队列（`stats.warmup_queue` 不看 mode）。
- 实现：Python 在 `dgy/routes/bank.py`，复用 `web.redirect / safe_back / now`、`srs.GRADES`；Worker 在 `edge/src/routes.ts`，复用 `isGrade`、`db.recordReview`、`safeBack`（带 uid）。
- 「今天已评」查询：Python `db.py` 新增 `graded_on(conn, day) -> dict[int, str]`（当天每题最后一次的 grade），Worker `db.ts` 同名带 `user_id`。章节页和打分守卫都用它。

### 2. 章节页路由

`chapter()`（Python `dgy/routes/bank.py:36`；Worker `/bank/:code`）：
- 接收 `kp` 查询参数，从 `content.outline(code)` 展平出考点列表 `[(section, kp, qs)]`，选中当前考点；越界 → 默认规则。
- 传给模板：章节、考点树（每节点 done/total，复用 `state.status`；排除的题不计入 total）、当前考点和它的题、`content.texts`、`graded_today`、上一个/下一个考点链接（含跨章）。
- 树的统计和「默认考点」是纯展示逻辑，放在路由里或 `stats.py` 一个小函数，Python 和 TS 写成一样。

### 3. 模板 / 视图

- `dgy/templates/_macros.html`：
  - `question_body(q, text, data_correct=false)`：选择题且有 `answer_key` 时给对应 `<li>` 加 `data-correct`（题目页、练习页调用不变）。
  - 新增 `qcard(q, text, status, index, today_grade, back)`：`<article class="qcard" id="q-N">` = 题头（`.qc-num` 方框、出处、面包屑、星级、分钟、原图/文字切换、不做了、详情）+ `question_body` + `.qc-actions`（两个 `.js-qc-toggle` + 打分表单）+ 两个面板：`.qc-panel[data-panel=answer]`（答案文字/勘误/答案原图，取自 `answer_body` 的前半）和 `.qc-panel[data-panel=solution]`（解析图）。为此把 `answer_body` 拆成 `answer_part` + `solution_part` 两个宏，原 `answer_body` 由这两个拼成，现有页面输出不变。
- `dgy/templates/bank_chapter.html` 重写为：`page_class` = `page-drill`；`.drill` 两栏网格 = `nav.kp-tree` + `div.drill-main`（`.drill-head` sticky 子顶栏 + 进度线 + 题卡列表）。加载 KaTeX（`katex_head/katex_script`）。
- Worker：`edge/src/views/parts.ts` 对应 `questionBody(..., dataCorrect)`、`answerPart`、`solutionPart`、`questionCard`；`edge/src/views/bank.ts` 的 `chapterPage` 重写成同样结构，标签和 class 与 Jinja 逐字对齐。

### 4. 样式 `dgy/static/css/app.css`（只改这一处，export 拷到 Worker）

沿用现有 token（`--accent`、`--mastered-*`、`--line`、`--radius-sm`…），深色模式自动跟随，不新增颜色。
- `.page-drill`：去掉 1120px 限宽，左栏 260px + 内容区（内容最大 ~980px）。
- `.kp-tree`：sticky、独立滚动；节点行 = 名称 + `done/total`，下方 3px 进度条（`--accent` 填充，全对时 `--mastered`）；当前项 `--accent-soft` 底、`--accent` 字。
- `.drill-head`：sticky 在原顶栏下（`top: 60px`），磨砂 `--glass` 背景，底边进度线。
- `.qcard`：白卡片、圆角、`scroll-margin-top`；`.qc-num` 小方框；选项在题卡里改成参考站的方框样式（`border: 1px solid var(--line)`，不再是灰底）；`.show-answer li[data-correct]` → `--mastered-soft` 底 + `--mastered` 边 + 右侧 `::after "正确答案"`。
- `.qc-actions`：左边两个文字按钮，右边三个描边打分按钮，选中态用各自 soft 色；`.js .qc-panel:not(.is-open){display:none}`（与现有 `.reveal-panel` 同一套路，没 JS 时全展开；图片都是 lazy，隐藏时不加载）。
- 720px 以下：打分按钮整行三等分，选项单列。打印：隐藏树、子顶栏、按钮。

### 5. 脚本 `dgy/static/js/app.js`

- 题卡开关：事件委托 `.js-qc-toggle` → 切换对应 `.qc-panel.is-open`、`aria-expanded`、文案「查看/隐藏」，查看答案时给卡片加 `.show-answer`；展开后对面板 `renderMath`。
- 原图/文字切换：`sheets` 选择器从 `.sheet` 扩到 `.sheet, .qcard`（`localStorage` 读取提到循环外）。
- 树的收起（考点名按钮）和窄屏「目录」开关：切换 `.drill` 上的 class，状态存 `localStorage`（try/catch）。
- 打分后整页 303 回到 `#q-N`，已展开的面板会收起——先接受，不做 fetch 无刷新。
