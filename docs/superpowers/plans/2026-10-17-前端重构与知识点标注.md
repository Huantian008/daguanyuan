# 前端重构、删除计时、逐题标注知识点

用户已批准本计划并要求实现。部署前另行确认。

## 目标与约束

- 界面更舒适、清爽、现代：统一设计变量，跟随系统的深色模式，顶栏可手动切换（跟随系统 / 浅色 / 深色），本机浏览器记住选择。
- 删除计时：练习页计时器、用时记录、“今日分钟”和记录里的用时都去掉。D1 与 SQLite 的 `elapsed_sec` 列保留不动，不做迁移；书上的“建议 X 分钟”保留。
- 练习页只留两个开关：「答案与解析」（空格，S 为别名）一次展开答案和解析；「知识点」（K）展开本题标注的知识点小节。
- 每题标注 1–3 个文字版小节（主小节在前），可从题目跳到文字版小节和原版页；知识点页反向列出本节题目，可直接开练。
- 两份实现同时改、各自测试；前端 CSS/JS 只改 `dgy/static/` 一处。本机版断网可用，不加外部字体或新依赖。

## 标注数据

- `dgy/sections.py` 从 `knowledge-md/0[1-9]_*.md` 带编号的 h2/h3 生成小节目录：主键 `"01/7.3"`，anchor 与页面渲染一致，原 PDF 页码来自隐藏注释 `<!-- p.N -->`，再按 `00_总目录.md` 的页码区间换算成原版页序号。
- 标注结果存 `knowledge-md/question_links.json`（只有编号，进 git）；文件缺失时功能自动不显示，退回整章链接。
- 逐题标注交给 DeepSeek Harness，任务说明见 `docs/deepseek/题目知识点标注.md`：先给 178 个考点组定默认小节，再逐题增删，每题附把握高低和简短理由。
- `pipeline/link_questions.py` 只做确定性的部分，不调用外部接口：
  - `prepare` 从做题本抽题干文字，生成小节目录（含正文摘录）和考点分组；
  - `check` 校验齐全、key 合法、章节一致，列出低把握和抽查样本；
  - `check --write` 在审核后写入 `knowledge-md/question_links.json`。

## 界面

- 练习页的知识点面板列出小节，点击后侧边抽屉直接显示该节正文：前端取该章文字版页面，按 anchor 截取，按需加载 KaTeX，不新增接口。
- 题目详情页常显相关小节；知识点文字版每个有题的小节下插入状态芯片和「练这 N 题」；原版页每页下列出相关题目。
- 深色模式下题图放在暖白纸面上并略压暗，不反色。

## 验收

- Python 全量测试（含 PDF）、Worker 测试与类型检查通过。
- 内置浏览器在桌面 1280 与手机 375、浅色与深色下检查各页面；练习页快捷键、抽屉 Esc 与焦点返回正常；375 宽无横向滚动，打分按钮不少于 44px。
- 本地 Worker 抽查练习页与知识点页，与 Python 版结构一致。
- 抽查 40 题标注，复核低把握题。
