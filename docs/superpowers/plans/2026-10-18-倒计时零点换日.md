# 首页日期和倒计时 0 点换日

## Context

首页「今天的数学」下面的日期和「考研初试 · 还有 N 天」用的是学习日（上海时间 04:00 换日），所以 0 点到 4 点之间
还显示前一天、倒计时也不减。用户要这两处在 0 点就换。

## 设计

- 新增按上海日历日算的 `calendar_day()` / `calendarDay()`，放在 `studyday.py` / `studyday.ts`。
- 只有首页顶部的日期和倒计时改用它；做题记录、热身、到期复习、今日题数、连续天数、学习记录页的分组都仍按学习日
  （凌晨 4 点前做的题算前一天）。
- 所以 0 点到 4 点之间，首页顶部已是新的一天，而这段时间做的题还记在前一天。这是用户确认过的取舍。

## 测试

- `calendar_day` / `calendarDay` 单元测试：23:59、00:30、03:59、04:00。
- 首页：晚上 9 点和过了 0 点、4 点前各看一次，日期和倒计时在 0 点换，热身/复习等仍按学习日。
