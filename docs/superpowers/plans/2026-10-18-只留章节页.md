# 只留章节页：首页「继续往下做」指回章节页，热身和复习改成题卡列表

## Context

2026-10-18 在线上站发现两件事，用户确认要改：

1. **首页「继续往下做」指错了地方**。它读的是最近一个没做完的「练习组」（`latestOpenSession`），而练习组的入口
   10-17 已经被章节页取代，在章节页做题（`mode = "browse"`）不会动它。结果用户刚在「一元积分 / 分母质因式」做完，
   首页还让他「继续上次」去做一个旧的「一元微分 / 导数概念 / 基本概念题」练习组。
2. **一题一题的练习页不要了**。用户只用章节页那种题卡铺开的做法。首页的「热身」「到期复习」也走练习页，
   用户选了：改成和章节页一样的题卡列表。

不做：每日建议量、快捷键（用户明确不要）。

## 设计

### 首页第 3 步「继续往下做」

- 取最近一条**不是**热身/复习（`mode` 不是 `warmup` / `due`）的自评记录，那道题所在的考点就是「上次做到的地方」。
- 从那个考点起按书序往后找（跨章，到底再从头绕回来）第一个还有没做过的题的考点，链接到 `/bank/<章>?kp=<序号>`。
- 卡片显示：这个考点还有几题没做、「章 / 小节 / 考点」，按钮「继续上次」+「换个考点」。
- 一题都没做过：从第一章第一个考点开始，按钮叫「开始做题」。全做完：显示「整本题库都做过一遍了」+「去题库」。
- 纯函数 `onward_kp()` / `onwardKp()` 放在 `drill.py` / `drill.ts`，两边写成一样。

### 热身、到期复习改成题卡列表

- 新页面 `GET /review/warmup`、`GET /review/due`（别的值 404），版式是章节页的题卡（复用 `qcard` / `questionCard`），
  没有考点树；页头写「已评 X / N 题」，页尾一个「回首页」。
- 列表 = 今天在这一页评过的题（按评的先后）+ 还要做的题（原来的 `warmup_queue` / `due_queue`）。评过的题留在页上，
  显示「今天已评」，所以评完一题、页面跳回 `#q-<题号>` 时下一张卡正好接在下面。
- 打分沿用 `POST /q/<num>/grade`，表单多一个 `mode`：`warmup` / `due` 原样记下，其余一律记 `browse`。
  一个学习日一题只记一次的规则不变。
- 首页「开始热身」「开始复习」从表单按钮改成链接；「优先巩固」的「去巩固」改成链到那个考点的章节页。
- 知识点页每节下面的「练这 N 题」按钮去掉（它开的也是练习组），题号 chip 照旧链到题目页。

### 删掉的东西

- 路由：`/practice/start`、`/practice/<sid>`、`/practice/<sid>/grade`、`/practice/<sid>/skip`。
- 模块：`queues.py` / `queues.ts`（只给练习组建队列）、练习页模板和视图、`start` / `startForm`、`knowledge_panel` /
  `knowledgePanel`、`db` 里练习组的读写函数，以及它们的测试；`app.js` 里只给练习页用的 1/2/3、→、K 快捷键；
  `app.css` 里练习页、评分条、「这组做完了」的样式。
- **不动数据库**：`sessions` 表和 `reviews.session_id` 列都留着（里面是历史数据），备份导出和
  `pipeline.export_progress` 照旧带上它们，不加迁移。

## 测试

- 两边原来借练习页测题目渲染的用例（文字版、答案勘误、知识点链接、无文字版退回图片等）改到章节页或复习页上测。
- 新增：首页第 3 步指向上次做到的考点、跳过已做完的考点、跨章、绕回、全做完；热身/复习页的列表和打分记的 `mode`；
  `/practice/...` 都是 404；两个账号看不到对方的热身/复习列表。
- `pytest -m "not pdf"`、`npx vitest run`、`npm run check` 全过；本机起 Python 版，在浏览器里点一遍首页、热身页、章节页。
