# 当天随时改评价

## Context

题卡上点了「不熟练 / 不会 / 掌握」之后，三个按钮当天就锁住、显示「今天已评」，点错了改不回来。用户要随时能改，
不要「今天已评」这种锁。

## 设计

- 题卡的三个按钮任何时候都能点。当天评过的题高亮当天的评价（`is-picked`），不再 `disabled`，也不再显示「今天已评」。
- 同一个学习日再点别的评价，**改掉当天那条记录**，不新增记录：
  - 卡片按「今天之前的记录」从头推一遍（`card_from` / `cardFrom`），再按新评价排期，等于第一次就点对了；
    `reps`、`lapses` 不会多算，等级也不会因为点了两次而多跳一级；
  - 能这样推，是因为每张卡片本来就是逐条记录过 `schedule()` 得来的，`schedule` 从没改过；
  - 那条记录保留第一次的时间和 `mode`：在热身页改评价，题还留在热身页，「继续往下做」也不受影响；
  - 万一同一天有重复记录（并发的双击），改评价时合并成一条。
- 点和当天一样的评价什么都不变，双击仍只算一次。
- 过了 04:00 换学习日再点，照旧记一条新的。
- 热身 / 到期复习页顶上的「今天已评 N / M 题」是进度计数，不是锁，不改。
- 不改表结构，线上不需要迁移。

## 改动

- `srs.py` / `srs.ts`：`card_from` / `cardFrom`。
- `db.py` / `db.ts`：`record_review` / `recordReview` 区分当天第一次和改评价。
- 打分路由去掉「今天评过就不记」的判断。
- `_macros.html` / `views/parts.ts`：去掉「今天已评」和 `disabled`；`app.css` 去掉对应样式，没被选中的按钮不再变灰。
- `AGENTS.md`、`CLAUDE.md` 里「一个学习日一题只记一次」的说明。

## 测试

- `card_from` / `cardFrom`：空记录是新卡；多条记录等于逐条 `schedule`。
- 数据库层：当天改评价后记录只有一条、评价是新的、时间和 mode 不变，卡片等于只评一次新评价；有更早的记录时从更早的状态推；
  评价相同什么都不变；第二天照常新增；并发留下的重复记录被合并。
- 页面：章节页评过之后按钮没有 `disabled`、没有「今天已评」，当天改评价后做题记录只有一条且是新评价；
  热身页改评价，题还在热身页，`mode` 仍是 `warmup`。
