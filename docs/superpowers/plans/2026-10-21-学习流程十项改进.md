# 学习流程十项改进

用户授权落实本轮审查的全部十项。保留题号、章节题卡流程及凌晨 04:00 学习日；同时修改 Python 与 Worker，不操作真实学习数据。

1. D1 做题历史按不超过 99 道题分批查询。
2. 为排除题目、设置、退出登录补齐账号归属校验，与评价接口一致。
3. 页面携带学习日，跨日清理当天选中状态；评价携带日期，服务端拒绝过期提交。
4. 保留跨天未同步评价，展示可查看和确认移除的待处理列表，禁止自动记到新一天。
5. 区分网络错误、登录失效、账号变化和日期变化；增加有限退避重试、手动重试与请求超时。
6. 首页和热身页从同一查询获得最近实际学习日的记录，不受 60 / 400 天窗口差异影响。
7. 继续上次链接定位到首张未做题卡。
8. 章节提供全部、未做、不会、不熟练筛选；保留题卡原有序号，评价后不立即隐藏正在操作的题卡。
9. 搜索支持多关键词、空白归一化、科目与状态组合筛选，保留精确题号直达。
10. 解析图片提供可键盘操作的放大弹窗、缩放、拖动、关闭和焦点恢复。

## 实施结果

以上十项均已在代码中落实。后端、模板在 Python 与 Worker 两端同步，前端资源只修改 `dgy/static/` 再导出到 Worker。

- D1 历史查询按 99 道题分批，测试替身也限制每条语句最多 100 个参数，避免回归。
- 排除、设置、退出与评价均校验页面所属账号；未登录的 JSON 请求返回可识别的 401。
- 页面与提交均携带学习日，跨 04:00 后同一评价可以再次提交；服务端阻止过期评价记入新一天。
- 待保存列表保留过期项，支持核对后移除；网络故障最多自动重试三次，并保留手动重试。卡片与列表均准确显示重试耗尽、登录失效、账号变化、日期变化。
- 首页和热身采用相同的最近实际学习日查询；继续上次定位到第一张未做题卡。
- 章节筛选保留原题卡序号和总体进度；搜索支持多个关键词、全半角与空白归一化、科目和状态组合筛选。
- 解析图片支持放大弹窗、缩放、适合屏幕、鼠标拖动、触摸滚动与关闭后焦点返回；没有脚本时仍能打开原图。
