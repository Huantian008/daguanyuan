# 移除解析图片悬停提示

用户要求去掉截图中的“点按放大”文字提示，保留放大镜光标，并直接部署上线。

1. 从 Python 与 Worker 的解析图片链接中移除 `title="点按放大"`。
2. 保留 `cursor: zoom-in`、点击放大和 `aria-label="放大解析图片"`。
3. 更新现有图片链接断言，导出资源并运行发布检查；部署后核对线上结果。
