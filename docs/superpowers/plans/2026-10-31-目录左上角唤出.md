# 目录改从左上角唤出

用户的副屏接在主屏左边，光标往副屏移动时会穿过窗口左边缘，自动隐藏的目录就会误弹出来。先后试过两版：

- 题目左侧放一条细把手、停 0.2 秒才弹出（方案 B）。用户不要中间的细条。
- 现在这版：参照 Claude 的做法，只有窗口左上角一块看不见的区域能唤出目录。

## 做法

- 触发区：窗口左上角，`clientY <= 160` 且 `clientX <= max(32, 目录左边距 + 12)`（1280 宽约 32px，越宽的屏幕越宽，不盖到标题文字）；页面上不显示任何东西。
- 光标在触发区停 0.18 秒才弹出；没停够就离开触发区，或离开浏览器窗口（`mouseout` 且 `relatedTarget` 为空），都取消。左边缘其他高度不再触发。
- 弹出后光标移进目录照常使用，离开约 0.3 秒收回；键盘 Tab 进入目录照样弹出。
- `peekPanel` 增加 `rest` 参数，顶部区域传 0，行为不变。
- 只改 `dgy/static/js/app.js` 和 `app.css`，模板不变。

## 验证

- 后台标签里用脚本模拟指针事件：左边缘中下部、快速穿过左上角、到左上角后离开窗口都不弹出；停 120ms 未弹出、220ms 弹出；在目录内 500ms 保持；离开 150ms 仍在、400ms 收回。
- 用户在本地 demo 上试用后确认“没啥问题”，要求发布上线并 push。
