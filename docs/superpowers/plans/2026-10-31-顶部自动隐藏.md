# 顶部和目录自动隐藏

- 题库章节页的两块区域各加一个图钉图标按钮（`aria-pressed`）：
  - 顶部（顶栏 + 标题栏）：图钉在标题栏右端，默认“固定”，行为与现在相同；选择存 localStorage `dgy-top-pinned`。
  - 左侧考点目录：图钉在目录最上面一行；“固定”就是现在的双栏，“自动隐藏”时题目区占满宽度。选择存 `dgy-tree-hidden`（新键，不沿用旧的 `dgy-tree-closed`），所以以前收起过目录也会先回到固定状态。
- 用户要求：两处默认都是钉住的，只有用户点图钉才会隐藏。
- 自动隐藏时：
  - 顶部在页面滚到标题栏贴顶后，顶栏和标题栏一起向上滑出；鼠标移到窗口上边缘约 24px 内时滑回。
  - 目录收在窗口左侧外面；鼠标移到窗口左边缘约 16px 内时，目录以浮层从左滑出，位置与固定时对齐。
  - 滑出用快起慢停的缓出曲线，滑走用缓入曲线；鼠标离开区域约 0.3 秒后滑走；键盘焦点进入时也会滑出。
  - 顶部隐藏期间目录上移贴顶；跳转到题卡锚点时少留顶部空白。
- 只在有鼠标悬停且宽于 960px 的屏幕启用：此时标题栏里原来的目录开关图标不显示，由目录里的图钉代替。手机、平板和窄屏不显示图钉，目录开关和顶部行为不变。系统开启“减少动态效果”时没有动画。
- 改 `dgy/templates/bank_chapter.html` 与 `edge/src/views/bank.ts` 两处模板，样式和脚本只改 `dgy/static/`。
- 本地用临时数据库在浏览器里检查两个图钉的切换、滚动隐藏、边缘唤出、移开收回、刷新后的记忆和窄屏回退；跑 Python 与 Worker 全量测试。部署前再问用户。
