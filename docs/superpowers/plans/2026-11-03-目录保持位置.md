# 换考点时目录保持原位

用户在章节页左边目录点一个考点，页面整页加载后目录跳回顶部：看着「导数计算」，点一下就变成「导数概念」，当前考点还可能被滚到看不见的地方。

原因：每个考点是一次整页跳转，目录是独立的滚动区域，新页面从 0 开始，没有代码恢复它。本地复现过：目录滚到 480，点考点后 `scrollTop` 为 0，当前考点在目录顶部下方 1050px，看不见。

## 做法

用 `sessionStorage` 按章记位置，键名 `dgy-tree-scroll:<pathname>`，每个标签页各记各的。不改服务端，也不改数据库。

- 保存：`app.js` 在 `pagehide` 时存 `tree.scrollTop`，点目录、翻节、筛选都覆盖。`clientHeight` 为 0（窄屏抽屉关着）时不存，以免写成 0。
- 绘制前恢复：`app.js` 是 `defer` 的，在里面恢复可能先闪一下顶部。所以在 `</nav>` 后面放一行内联脚本，Jinja 片段 `_tree_scroll.html` 和 `views/bank.ts` 的常量 `TREE_SCROLL` 各一份，`edge/test/content.test.ts` 检查逐字一致，做法和 `_theme_head.html` 相同。
- 当前考点可见：`app.js` 的 `placeTree()` 在 `show()` 之后调用，先恢复位置，`.is-current` 仍在可视范围外就滚到目录正中，处理从首页或别章进来、连续点「下一节」的情况。直接算 `tree.scrollTop`，不用 `scrollIntoView`，它会连带滚动整个页面。
- 目录收起后再打开：`display: none` 会把滚动位置清零，`flip()` 打开目录后如果 `scrollTop` 为 0 就调用一次 `placeTree()`。鼠标宽屏收起时目录只是移到屏幕外，位置还在。
- 存储被禁用时跳过，退回到只保证当前考点可见。

右边题目区仍从新考点的第一题开始。

不做局部刷新：换考点还是整页加载，只是目录不动。局部刷新要处理题卡事件、KaTeX 重新渲染、顶栏内容和前进后退，离初试不远，风险不值得。

## 验证

- Python 和 Worker 全量测试，新增：
  - 保存和恢复位置、不用别章的位置；
  - 当前考点在可视范围外时滚到正中；
  - 抽屉关着不覆盖、打开时恢复；
  - 存储被禁用时不报错；
  - 内联脚本紧跟 `</nav>`，两边逐字一致。
- 用临时数据库起本地站，真实题库，检查：
  - 宽屏点目录、翻节、筛选，位置不变；
  - 换章和从别处进入较深的考点；
  - 收起再展开，收起时翻节；
  - 375 宽抽屉；
  - 采样确认新页面不会先显示目录顶部。
