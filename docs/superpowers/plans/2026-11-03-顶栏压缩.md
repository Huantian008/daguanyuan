# 顶栏压缩：一条细顶栏 + 贴边侧边栏

用户觉得章节页不好用，要学 Claude Desktop 的布局：压缩上面那栏，把侧边栏的按钮放到上面那一栏。另外顶栏的「大观园」很突兀，网站是自用的，页面上不再显示。

现在章节页顶部叠着 60px 的顶栏和约 80px 的吸顶标题卡，下面还有一行筛选；目录图钉、顶部图钉、窄屏目录开关分散在三处。

## 做法

- 去掉品牌：删顶栏的图标和名字，回首页用导航的「首页」；登录页标题改成「登录」。浏览器标签页的图标和标题保留。
- 顶栏（所有页面）：高 44px（手机 48px，变量 `--bar-h`），通栏贴边；导航、Aa、主题按钮缩小减淡。导航仍在顶栏。电脑上其他页面的导航左边留出开关的位置，进出章节页时导航不跳。
- 侧边栏开关：放在顶栏最左边，只有章节页有。替代目录图钉和原来的目录开关，所有设备都用这一个按钮。记忆继续用 `dgy-tree-hidden`。
- 目录：贴窗口左边的平面侧边栏，无卡片、无圆角，只有右侧分隔线，从顶栏下方铺到窗口底部。隐藏后题目区加宽（上限 1280px，和原来一样）；鼠标在左上角停 0.18 秒仍会唤出，触发区覆盖开关按钮。点击收起时立刻收走，鼠标离开触发区之前不再弹出。
- 标题卡拆开：考点名、小节、做过数和筛选合成一行，不吸顶，随页面滚走。上一节/下一节、进度线、顶部图钉进顶栏。页面底部的翻节按钮保留。标题行滚出视野后，顶栏才显示考点名。
- 顶部自动隐藏保留：现在只收顶栏这一条，不再需要 `--top-shift` 和 ResizeObserver。
- 窄屏（≤960px）：目录是从左侧滑出的抽屉，点外面关闭。≤720px 时翻节按钮显示在标题行。没有脚本时开关不显示，目录直接展开在页面里。
- 改 `base.html`、`login.html`、`bank_chapter.html` 与 `layout.ts`、`login.ts`、`bank.ts` 两边模板，样式和脚本只改 `dgy/static/`。调度、评分、数据库不动。

## 验证

- Python 和 Worker 全量测试，新增：开关在顶栏内、其他页面没有开关、目录图钉已删除、页面没有品牌。
- 用临时数据库起本地站，在 1440、1000、768、375 四种宽度和浅色深色下检查布局；检查开关、刷新记忆、左上角唤出、顶部自动隐藏、评价后计数和进度线就地更新、题卡锚点、窄屏抽屉；其他页面不走样。部署前再问用户。
