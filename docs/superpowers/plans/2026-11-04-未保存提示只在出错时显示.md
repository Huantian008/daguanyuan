# 「未保存的评价」只在真没存上时显示

用户点「不熟练」「不会」「掌握」时，页面顶部先弹出「未保存的评价 · 正在保存」，存完又收起。评价其实没问题，但这个框把题卡连同按钮往下推。

原因：评价在点击时先写进 `localStorage`，服务器确认后才删，这样断网、关页面都不丢。`renderPending()` 只要里面有条目就显示这个框，所以每次正常保存都会经过它。本地复现过：请求返回 200，框照样出现，题卡下移 138px，按钮离开了鼠标；线上响应慢（`/login` 首字节 0.35–0.9 秒，第一次 3.7 秒），所以看得很清楚。

## 做法

`renderPending()` 只列已经失败（`failures` 有记录）或已跨学习日的条目。写入 `localStorage`、补交和重试的逻辑都不变。

- 正在发送、还没失败的条目不显示，包括上次留下、打开页面时补交的。
- 失败过的条目在自动重试期间留在框里，不会闪。
- 请求卡住时，到 15 秒超时才显示。

只改 `dgy/static/js/app.js`，Worker 版在 export 时拷过去，不改服务端和数据库。

## 验证

- Worker 测试新增三条：保存成功时框从未显示（含第一次请求没回来就点第二下）；上次留下的评价补交时不显示；失败后显示并在重试期间保持，成功后收起。
- Python 和 Worker 全量测试。
- 用临时数据库起本地站，真实题库，在浏览器里检查：
  - 三个按钮各点一次，框没有出现过，题卡位置不变；
  - 请求延迟 3 秒时同样不出现；
  - 模拟断网时框出现，恢复后自动重试成功并收起；
  - 过期条目照常显示，可以移除。
