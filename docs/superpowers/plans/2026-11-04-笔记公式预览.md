# 笔记里的公式预览

用户要在笔记里写公式能看到渲染结果。同时提过的粘贴截图，用户后来决定不做。

## 做法

笔记仍然是纯文本，存储和接口都不变。`app.js` 在文本框下面加一块预览，只有写了公式才显示，打字时即时更新，用站里已有的 KaTeX。题卡上的笔记收起时不渲染，点开时才渲染。

- 写法：`$…$`、`$$…$$`、`\(…\)`、`\[…\]`，`\$` 是美元符号。
- 单个 `$` 按 Pandoc 的规则判断：后面紧跟非空白才开始，前面紧跟非空白才结束，结束后不能紧跟数字，所以「$5 和 $6」还是文字。
- 普通文字用 `textContent` 写入，不会被当成 HTML。公式写错时由 KaTeX 标红，不会打断输入。
- 不用正则后顾（lookbehind）：旧版 Safari 遇到它整个 `app.js` 都解析不了。
- 单独成行的公式已经是一块，它前后的换行不再显示成空行。
- 页面只多一个隐藏的 `.note-preview`，Jinja 和 TS 两处都加；文本框提示写明公式的写法。

## 验证

- Worker 的 `app-script` 测试新增：公式切分、不算公式的写法、收起时不渲染；两边页面测试检查预览块存在。
- Python 和 Worker 全量测试。
- 用临时数据库起本地站，真实题库，在浏览器里用真实键盘输入，检查：
  - 行内公式、块级公式、写错的公式；
  - 刷新后重新打开；
  - 题目页；
  - 375 宽和深色。
