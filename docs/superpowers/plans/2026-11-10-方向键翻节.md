# 方向键翻节

用户要在章节页用键盘翻节：→ 是下一节，← 是上一节。

## 做法

- 章节页底部「翻节」导航里的两个链接加 `rel="prev"` / `rel="next"` 和 `title`（快捷键提示），Jinja 和 TS 两处都加。
- `app.js` 监听 `keydown`：← 找 `.drill-foot a[rel="prev"]`，→ 找 `rel="next"`，找到就点它。所以章首的「上一章」、章末的「下一章」
  和带着的筛选条件都跟按钮一致，没有对应链接时按键照常交给浏览器。
- 这些情况不翻：正在输入（输入框、笔记文本框、下拉）、带 Ctrl / ⌘ / Alt / Shift（留给浏览器的后退、选字）、按住不放的连发、
  输入法组字中、知识点抽屉或解析大图开着。
- 不新增服务端接口，数据库不变。

## 验证

- 两边页面测试检查链接上的 `rel`；Worker 的 `app-script` 测试检查按键行为。
- Python 和 Worker 全量测试。
- 用临时数据库起本地站，在浏览器里按真实按键检查翻节、跨章、笔记框里不翻、抽屉开着不翻。
