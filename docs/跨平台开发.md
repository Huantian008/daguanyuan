# 在 Windows 和 macOS 之间切换开发

代码继续使用已有的 GitHub 私有仓库（`https://github.com/Huantian008/daguanyuan`），切换电脑时拉取更新，不另建仓库。
首次开发所需的源 PDF 和现成题库图片通过同一仓库的私有 Release 下载。线上进度在 Cloudflare D1，换开发电脑无需迁移。

## 1. 两台机器上的目录

| 机器 | 项目位置 | 源 PDF 位置 |
|---|---|---|
| Windows | `E:\大观园\daguanyuan` | `E:\大观园\`（仓库的上一级） |
| macOS | 建议 `~/dev/daguanyuan` | `~/dev/`（同样放上一级） |

`pipeline/sources.py` 默认去**项目的上一级目录**找 PDF，所以两台上都保持这个相对关系最省事。
放别处就用环境变量 `DGY_SOURCE_DIR` 指过去。

> macOS 上不要把项目放在 iCloud Drive（`~/Documents`、`~/Desktop` 会被强制同步）里跑。
> SQLite 数据库被同步进程同时读写会损坏。

## 2. 首次搭建

### macOS

准备 Git、GitHub CLI（`gh`）、Python 3.11 以上（建议 3.12）和 Node.js 24；当前 Worker 依赖也支持 Node.js 22.12 以上的 22.x。
已有工作副本时，在原目录运行 `git pull --ff-only`，跳过下面的克隆步骤。

```bash
gh auth login
mkdir -p ~/dev
cd ~/dev
gh repo clone Huantian008/daguanyuan
cd ~/dev/daguanyuan
```

登录有权访问此私有仓库的账号，然后下载缺少的开发资料：

```bash
mkdir -p ~/Downloads/daguanyuan-mac-dev-20261017
gh release download mac-dev-20261017 \
  --repo Huantian008/daguanyuan \
  --pattern 'daguanyuan-mac-dev-20261017.tar.gz' \
  --pattern 'SHA256SUMS.txt' \
  --dir ~/Downloads/daguanyuan-mac-dev-20261017
cd ~/Downloads/daguanyuan-mac-dev-20261017
shasum -a 256 -c SHA256SUMS.txt
tar -xzf daguanyuan-mac-dev-20261017.tar.gz -C ~/dev
cd ~/dev/daguanyuan
```

也可从 [Mac 开发资料下载页](https://github.com/Huantian008/daguanyuan/releases/tag/mac-dev-20261017) 手动下载两个文件。
资料包约 246 MiB，包含构建必需的 5 份源 PDF、2,717 个 `content/` 文件和逐文件 SHA-256 清单；不含密码、学习数据库或运行环境。
解压到 `~/dev` 后，源 PDF 在项目上一级，现成题库在 `daguanyuan/content/`。如果已有工作副本且改过生成物，先保留本机的 `content/`，解压会覆盖同名文件。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pipeline.validate
.venv/bin/python -m pipeline.export_edge
cd edge
npm ci
npm run types
npm test
npm run check
cd ..
.venv/bin/python -m pytest -m 'not pdf'
.venv/bin/python -m dgy --reload --data-dir /tmp/daguanyuan-dev
```

打开 <http://127.0.0.1:8000/>。开发记录写入独立临时数据库，不会同步到线上。
首次搭建已有现成题库，无需运行 `pipeline.build`；修改提取逻辑或更新源 PDF 后才重新构建。
开发 Worker 时，在 `edge/` 复制 `.dev.vars.example` 为 `.dev.vars`，自行填写本地密码与随机密钥，执行
`npx wrangler d1 migrations apply dgy --local`，然后 `npm run dev`。这些步骤只操作本地环境。

### Windows

见 `README.md` 的「第一次使用」。差异只有虚拟环境路径（`.venv\Scripts\python.exe`）。

## 3. 不在 git 里的资料

git 忽略了 PDF、`content/`、`data/` 等。首次完整开发请下载上面的资料包；其中已包含 `pipeline/sources.py` 引用的 5 份源 PDF 和现成题库。
如果不用资料包，也可按原目录结构手动复制所需 PDF。整个资料合集和混合版题本不是构建的必要输入。
以下两项只在迁移**离线版真实进度**时考虑，Mac 开发不需要：

| 要拷的 | 大小 | 为什么必须 |
|---|---|---|
| `data/app.db` | 依本机记录而定 | 离线版做题记录；开发时使用独立数据库，线上进度无需复制 |
| `data/secret_key` | — | 不必复制，Mac 会生成本机会话密钥 |

拷 `app.db` 之前**先关掉网站**，否则可能拷到写了一半的数据库。

### 不需要拷的（能重新生成）

| 目录 | 大小 | 怎么重新生成 |
|---|---|---|
| `content/` | 65.5 MB | `.venv/bin/python -m pipeline.build` |
| `edge/public/` + `edge/src/generated/` | 67.4 MB | `.venv/bin/python -m pipeline.export_edge` |
| `edge/node_modules/` | 228 MB | `npm ci` |
| `.venv/` | 17.8 MB | `python3 -m venv .venv`（Windows 的 `python.exe` 在 macOS 上无用） |
| `data/releases/` | 69.8 MB | 只是历次验收的本地证据，不必同步 |

## 4. Google Drive 的使用边界

**不要把整个工作副本放进 Drive 同步**，原因：

1. `.git/` 有大量零散小对象文件（近 500 个），Drive 是文件级同步，容易产生冲突副本并损坏仓库。
2. `.venv/` 和 `node_modules/` 每个平台不同，同步过去也不能用，白白占用上传时间。
3. `data/app.db` 是 SQLite 单文件库，网站运行时被 Drive 同时读写会损坏。

**可选做法**：代码走 GitHub，Drive 可用于额外备份或以后单独传输更新的源资料；本次首次开发资料已通过私有 Release 提供。
把 `data/app.db` 放进 Drive 当额外备份也可以，但同样遵守「先关网站再同步」。

## 5. 两平台命令对照

| 用途 | Windows | macOS |
|---|---|---|
| 跑网站 | `.venv\Scripts\python.exe -m dgy` | `.venv/bin/python -m dgy` |
| 重新提取题库 | `.venv\Scripts\python.exe -m pipeline.build` | `.venv/bin/python -m pipeline.build` |
| 跑 Python 测试 | `.venv\Scripts\python.exe -m pytest` | `.venv/bin/python -m pytest` |
| 导出线上资源 | `.venv\Scripts\python.exe -m pipeline.export_edge` | `.venv/bin/python -m pipeline.export_edge` |
| Worker 测试 / 类型检查 | `cd edge` 后 `npm test` / `npm run check` | 相同 |
| 启动（快捷） | 双击 `start.bat` | 无脚本，用上面的命令 |

## 6. 每次切换机器前的习惯

1. 在离开的机器上 `git status` 确认没有未提交的改动——**worktree 里的改动最容易漏**。
2. 提交并 `git push`。
3. 只有需要迁移离线版真实进度时，才在停掉离线网站后单独备份 `data/app.db`；不要上传数据库或密码到 GitHub。
4. 到新机器在已有工作副本内 `git pull --ff-only`。依赖变化时重新安装；静态资源或知识点变化后重新运行 `pipeline.export_edge`。

资料包是 2026-10-17 的内容快照，不会随 `git pull` 自动更新。线上做题继续登录 Cloudflare 网站，使用同一份线上进度。
